INTERACTIVE IMAGE GALLERY — COURSERA PROJECT

Included files:
- index.html: six images, descriptive alt text, document title and semantic page structure.
- style.css: responsive grid, image box-model styling, hover/focus styles, and visible keyboard focus.
- script.js: load listener, console.log messages, for loop adding tabindex="0", mouseover/mouseleave and focus/blur listeners.

TEST LOCALLY:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Hover over each image.
4. Press Tab and Shift+Tab to navigate through images and observe the highlight.
5. Open Developer Tools → Console to see load/tabindex messages.

VALIDATION REQUIRED:
This project has NOT yet been run through external validators. Test the published page with:
W3C HTML Validator: https://validator.w3.org/
WAVE: https://wave.webaim.org/
axe DevTools: https://www.deque.com/axe/devtools/

Fix any issues reported and rerun the checks. Do not claim it passed until you have actually run the tools.

PUBLISH:
Upload index.html, style.css, and script.js to a public GitHub repository. Enable GitHub Pages in Settings → Pages, then test the public URL with W3C and WAVE. Install the axe DevTools browser extension to run axe on the published page.

PEER REVIEW:
Submit the published URL. Reviewers can open the page and use View Page Source or inspect the repository files.
